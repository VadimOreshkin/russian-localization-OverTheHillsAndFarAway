# 🇷🇺 Russian Localization for Over The Hills And Far Away

**Full Russian translation of dialogues, interface, and character names.**

---

## 📖 English

### 📌 Overview

This is a **complete Russian localization** for the visual novel *Over The Hills And Far Away*.

The translation includes:
- 100% of the game's narrative (dialogues, descriptions, monologues, dreams)
- Full interface translation (menus, buttons, settings, save/load screens, journal)
- Localized character names (Aubrey → Обри, Mai → Мая, Jackson → Джексон, etc.)
- Adapted Ruby text (small annotations above words) for Shawnee language inserts
- Custom code adjustments to preserve all button functionality and UI behavior

### 🛠 What has been modified

- **All game scripts** — fully translated while preserving the original Ren'Py syntax
- **Interface files** (`screens.rpy`) — all UI elements, menus, tooltips, and confirmation dialogs are localized
- **Character definitions** — names are now displayed in Russian throughout the game
- **Minor code additions** — fixed potential button breakage and ensured UI stability (e.g., Quick Menu, History Log, Gallery navigation)

> No engine files were harmed. Everything works exactly like the original — but in Russian.

### 📦 Installation

1. **Download** the localization archive from this repository.
2. Locate your game installation folder:  
   `Steam → steamapps → common → Over The Hills And Far Away → game`
3. **Replace two files** inside the `game` folder with the ones from the archive:
   - `screens.rpy`
   - `script.rpy`
4. Launch the game. The interface and all text will now be in Russian.

## 🇷🇺 Русский

### 📌 О переводе

Это **полная русская локализация** визуальной новеллы *Over The Hills And Far Away*.

Перевод включает:
- 100% текста (диалоги, описания, монологи, сны)
- Полный перевод интерфейса (меню, кнопки, настройки, экраны сохранения/загрузки, журнал)
- Локализованные имена персонажей (Aubrey → Обри, Mai → Мая, Jackson → Джексон и т.д.)
- Адаптированный Ruby-текст (мелкие подписи над словами) для вставок на языке шауни
- Небольшие доработки кода для сохранения работоспособности всех кнопок и элементов интерфейса

### 🛠 Что изменено

- **Все файлы сценария** — полностью переведены с сохранением оригинального синтаксиса Ren'Py
- **Файлы интерфейса** (`screens.rpy`) — локализованы все элементы UI, меню, подсказки и диалоги подтверждения
- **Определения персонажей** — имена теперь отображаются на русском языке по всей игре
- **Небольшие дополнения в коде** — исправлены потенциальные проблемы с кнопками и обеспечена стабильность интерфейса (например, Quick Menu, History Log, галерея)

> Ни один системный файл движка не пострадал. Всё работает как в оригинале — но на русском.

### 📦 Установка

1. **Скачайте** архив с локализацией из этого репозитория.
2. Откройте папку с установленной игрой:  
   `Steam → steamapps → common → Over The Hills And Far Away → game`
3. **Замените два файла** внутри папки `game` на файлы из архива:
   - `screens.rpy`
   - `script.rpy`
4. Запустите игру. Интерфейс и весь текст теперь будут на русском языке.
